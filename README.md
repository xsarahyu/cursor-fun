# Scientific Calculator

A simple scientific calculator built with HTML, CSS, and JavaScript.

## How to run

Open `index.html` in a web browser (double-click the file or drag it into a browser window). No server or build step required.

## Features

- **Basic operations:** add, subtract, multiply, divide
- **Scientific functions:** sin, cos, tan, asin, acos, atan, log, ln, √, x², x^y, 1/x, ±
- **Constants:** π and e
- **Angle mode:** DEG/RAD toggle for trigonometry (click the DEG button to switch)
- **Number pad:** 3×3 layout (7–8–9, 4–5–6, 1–2–3) with 0 and decimal below

## Files

| File        | Description                    |
|------------|--------------------------------|
| `index.html` | Calculator layout and buttons  |
| `style.css`  | Layout and styling            |
| `script.js`  | Calculator logic and events   |
